# Learning Large Language Models with Hugging Face

This repository contains my implementations and experiments while following the Hugging Face Large Language Model (LLM) course.

The purpose of this repository is to practice and understand the fundamentals of transformer models and the Hugging Face ecosystem through hands-on coding.

---

## Topics Covered

- Hugging Face Pipelines
- Tokenization and encoding/decoding
- Handling multiple sequences
- Attention masks
- Loading and using pretrained models
- Hugging Face Datasets
- Data preprocessing and wrangling
- Model inference
- Fine-tuning basics
- Training loops
- Simple Streamlit applications

---

## Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- Hugging Face Datasets
- Tokenizers
- Streamlit

---

## Purpose

This repository is created for learning and experimentation while building a foundation in Large Language Models and Natural Language Processing.

All implementations are based on concepts learned from the Hugging Face LLM Course.
